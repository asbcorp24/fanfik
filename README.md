# Фанфик — библиотека сюжетов фильмов

PHP 8.1+ / SQLite (PDO SQLite). Сайт для чтения полных сюжетов, концовок, литературных адаптаций и альтернативных жанровых фанфиков.

## Установка

1. Разместите код на PHP-хостинге. Рекомендуется направить DocumentRoot в каталог `public/`.
2. Установите PHP-расширения `pdo_sqlite` и `mbstring`. Для кеширования постеров дополнительно нужен `curl`.
3. Скопируйте вашу готовую SQLite БД с таблицей `movies` в `storage/spoilers.db`, либо укажите абсолютный путь в `FANFIK_DB_PATH` (среда сервера).
4. Дайте PHP-процессу доступ на чтение `spoilers.db`. Для редактирования фильмов через админку нужны также права на запись в базу и её каталог. Для комментариев нужны права на запись в `storage/`.
5. Откройте сайт. На Apache при DocumentRoot в корне проекта маршрутизация работает через `.htaccess`, который направляет запросы в `public/`.

**Важно:** не размещайте SQLite-файл в `public/` или в другом доступном по HTTP каталоге. Каталог `storage/` заблокирован для Apache, а основная рекомендуемая схема — DocumentRoot `public/`.

## Разделы

- `/` — каталог фильмов с поиском и фильтрами по году, жанру и наличию текста.
- `/movie/{id}` — карточка фильма: сюжет, концовка, литературная версия и фанфики по жанрам.
- `/read/{id}/{type}` — читатель с переключателем темы, размера шрифта, ширины текста, запоминанием позиции.
- `/admin.php` — вход в админку: статистика, редактирование фильмов, модерация комментариев, смена пароля.

Столбцы `plot_ru`, `ending_ru`, `novel_ru`, `novel_erotic`, `novel_horror`, `novel_fantasy`, `novel_comedy`, `novel_detective`, `novel_thriller` используются напрямую; если русского перевода ещё нет, для сюжета и концовки показывается английская версия. Сайт не запускает перевод и генерацию текстов. Просмотр работает без прав на запись в `movies`, редактирование через админку требует таких прав.

## Разработка

```bash
php -S 127.0.0.1:8080 -t public public/router.php
```

Для тестирования создайте БД по вашей схеме `movies` и заполните её собственными данными. Демо-контент в репозиторий не входит. `storage/*.db*` и `storage/*.sqlite*` игнорируется Git.

## Локальный кеш постеров

Первый запрос `/poster.php?id=ID` загружает постер из `poster_url` в `public/assets/posters/`. Все последующие запросы используют сохранённый файл на сервере. Нужны PHP cURL и права на запись в `public/assets/posters/`. Поддерживаются JPEG, PNG, WebP, GIF размером до 5 МБ. Редиректы и приватные IP заблокированы. При изменении URL создаётся новый файл; устаревшие файлы можно удалять вручную.

## Комментарии

- Обсуждения доступны на главной странице, у каждого фильма, под сюжетом, концовкой, литературной версией и всеми жанровыми фанфиками отдельно.
- Каждый новый комментарий сначала получает статус `pending`, посетители его не видят до одобрения администратором.
- Для защиты от спама есть CSRF-токен, скрытое поле и ограничения: не более одного комментария в минуту и пяти в час с одного IP. Хранится только HMAC-отпечаток IP, не сам IP.
- При первом обращении к комментариям сайт автоматически создаст **`storage/community.sqlite`** и таблицы. Основная база `spoilers.db` при этом не изменяется. Альтернативный путь можно задать переменной `FANFIK_COMMUNITY_DB_PATH`.
- Комментарии отображаются постранично по 30 сообщений.

## Настройка администратора

Пароль **не задан по умолчанию**, в GitHub секреты не включены. Перед публикацией обязательно используйте HTTPS.

Самый простой способ создать пароль при наличии SSH/терминала:

```bash
php bin/set-admin-password.php
```

Введите новый пароль длиной от 12 символов дважды. Команда запишет **только хеш** в `storage/admin-password.hash` (файл исключён из Git). После этого откройте `/admin.php` и войдите. Позднее пароль можно менять в разделе «Настройки».

Если терминала на хостинге нет, установите переменную окружения `FANFIK_SETUP_TOKEN` со случайным значением **от 24 символов**, откройте `/admin.php` и введите ключ вместе с новым паролем. После создания администратора **удалите `FANFIK_SETUP_TOKEN`** из конфигурации сервера. Без ключа и без CLI создание первого пароля через браузер недоступно.

Администратор может редактировать оригинальные и русские названия, постер, жанры, сюжеты, концовки и все фанфики. Эти изменения записываются непосредственно в `spoilers.db`; перед редактированием сделайте резервную копию. Данные комментариев находятся отдельно в `storage/community.sqlite`.
