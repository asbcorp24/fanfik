# Фанфик — библиотека сюжетов фильмов

PHP 8.1+ / SQLite (PDO SQLite). Сайт для чтения полных сюжетов, концовок, литературных адаптаций и альтернативных жанровых фанфиков.

## Установка

1. Разместите код на PHP-хостинге. Рекомендуется направить DocumentRoot в каталог `public/`.
2. Установите `pdo_sqlite` и `sqlite3` для PHP.
3. Скопируйте вашу готовую SQLite БД с таблицей `movies` в `storage/spoilers.db`, либо укажите абсолютный путь в `FANFIK_DB_PATH` (среда сервера).
4. Убедитесь, что PHP-процесс может читать базу. Если база используется только для чтения, права на запись не нужны.
5. Откройте сайт. На Apache при DocumentRoot в корне проекта маршрутизация работает через `.htaccess`, который направляет запросы в `public/`.

**Важно:** не размещайте SQLite-файл в `public/` или в другом доступном по HTTP каталоге. Каталог `storage/` заблокирован для Apache, а основная рекомендуемая схема — DocumentRoot `public/`.

## Разделы

- `/` — каталог фильмов с поиском и фильтрами по году, жанру и наличию текста.
- `/movie/{id}` — карточка фильма: сюжет, концовка, литературная версия и фанфики по жанрам.
- `/read/{id}/{type}` — читатель с переключателем темы, размера шрифта, ширины текста, запоминанием позиции.

Столбцы `plot_ru`, `ending_ru`, `novel_ru`, `novel_erotic`, `novel_horror`, `novel_fantasy`, `novel_comedy`, `novel_detective`, `novel_thriller` используются напрямую; если русского перевода ещё нет, для сюжета и концовки показывается английская версия. Сайт только читает таблицу `movies`, не запускает перевод и генерацию текстов.

## Разработка

```bash
php -S 127.0.0.1:8080 -t public public/router.php
```

Для тестирования создайте БД по вашей схеме `movies` и заполните её собственными данными. Демо-контент в репозиторий не входит. `storage/*.db*` и `storage/*.sqlite*` игнорируется Git.
